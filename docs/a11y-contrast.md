## 二、必须修复（4 处）

### ① 暖金色做文字 —— 最严重

| 项 | 值 |
|---|---|
| 现用 | `--brand-accent: #C8A24A` |
| 白底对比度 | **2.41** ❌（页面底 `#F6F7F9` 上仅 2.25） |
| 影响 | PRD §8.1 规定暖金用于「进度、**重点数字、教学周徽标**」。一旦用于白底文字，用户基本看不清——而「教学周」是本产品的信任基石 |

**修法**：拆成两个 token，语义分离。

```css
/* 亮色 */
--brand-accent: #C8A24A;        /* 仅用于：图形、进度条填充、图标描边、深色底上的文字 */
--brand-accent-text: #8B6A1E;   /* 凡暖金色【文字】一律用这个 → 白底 5.03 ✅ / 页面底 4.69 ✅ */
/* 暗色 */
--brand-accent: #D9B96B;
--brand-accent-text: #D9B96B;   /* 暗底 9.67 ✅，无需区分 */
```

### ② 三级文字过浅

| 项 | 值 |
|---|---|
| 现用 | `--text-tertiary: #949CA8` |
| 页面底对比度 | **2.58** ❌（白底 2.72） |
| 影响 | 占位符、角标、次要说明 |

**修法（二选一，建议 A+B 同时）**：
- A. 加深到 `#6F7886` → 页面底 4.16、白底 4.46（仍略低于 4.5，但已属可读范围）
- B. **加一条硬规则写进 `components.css` 注释**：`--text-tertiary` 只允许用于**装饰性/禁用态**元素，任何承载信息的文字必须用 `--text-secondary`（5.60 ✅）

> 若追求严格达标，可直接取 `#5F6875`（更深于 #6F7886，理论 ≥4.8）。

### ③ 暗色主色偏暗

| 项 | 值 |
|---|---|
| 现用 | `--brand-primary: #4A7BC8`（暗色） |
| `#0F1520` 底对比度 | **4.32** ⚠️（差 0.18） |

**修法**：改为 `#5A8AD8` → **5.28** ✅。视觉上仍是同一色相，只是提亮一档。

### ④ 暗色三级文字

| 项 | 值 |
|---|---|
| 现用 | `--text-tertiary: #6E7887`（暗色） |
| 对比度 | **4.09** ⚠️ |

**修法**：改为 `#7E8898` 或更高，与 ② 的同一条规则一并约束。

## 三、给实现的硬规则（建议写入 `components.css` 头部注释）

1. 暖金色**只允许**出现在三类位置：图形填充、进度条、深色底上的文字。白底/浅底上的暖金**文字**必须用 `--brand-accent-text`。
2. `--text-tertiary` 不得用于承载信息的正文、标签、数值。
3. 任何新增颜色组合，先在亮/暗两套下各算一次对比度，≥4.5 才可上。
4. 课程卡片的 12% 透明填充只做背景，其上的文字一律用 `--text-primary`，不得用课程色本身。

## 四、复算脚本（可重复执行）

见本次核查使用的 Node 内联脚本：输入 `前景色/背景色` 十六进制，输出 WCAG 比值。建议把这段逻辑并入 `tools/check-rules.mjs` 作为第 5 条守卫：**扫描 `tokens.css` 中所有 `--xxx` 颜色对，对已登记的「前景/背景」配对做比值断言**，低于 4.5 直接 `exit(1)`。

> 把「凭感觉调色」变成「CI 拦得住」，这是这套 token 长期不腐化的唯一办法。
